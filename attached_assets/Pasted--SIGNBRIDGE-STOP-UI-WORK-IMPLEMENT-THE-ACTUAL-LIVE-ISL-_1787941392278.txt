# 7. TEMPORAL SIGN DETECTION

INCLUDE contains isolated sign videos.

The live camera is continuous.

Therefore implement a temporal buffer.

Conceptually:

camera frames
↓
hand landmarks/features
↓
temporal window
↓
sign prediction
↓
prediction stabilization
↓
sign boundary detection
↓
append completed sign

Example:

HELLO
↓
HOW
↓
YOU

The system should not append:

HELLO
HELLO
HELLO
HELLO

every frame.

Use temporal smoothing / debouncing.

Only commit a sign to the sequence after sufficient stable evidence.
